Welcome!
This is a short guide on how to set up a website the old-fashioned way,
working mostly from a terminal, using fairly primitive technology.
This is specifically for a **static website**
(like a personal page or small blog),
which means that you just need to put some content out,
without having to deal with a server.

## Jumping in

If you want to get started right away, jump to [Getting Started](/overview).

## Examples of websites

Here are some websites that were started
either by following this workflow or something close to it.
The simplest one is `ssg.evanchen.cc` which for pedagogical reasons
tries to use as many default settings as I can get away with,
rather than being feature-complete.

- [ssg.evanchen.cc](https://ssg.evanchen.cc),
  source at [vEnhance/ssg.evanchen.cc](https://github.com/vEnhance/ssg.evanchen.cc)
- [wall.evanchen.cc](https://wall.evanchen.cc),
  source at [vEnhance/wall.evanchen.cc](https://github.com/vEnhance/wall.evanchen.cc)
