Welcome!
This is a short guide on how to set up a website the old-fashioned way,
working mostly from a terminal, using old-school technology.
We use a [**static site generator** (SSG)][ssg],
suitable for say a personal site, blog, or product page.
(See [The Static Site Paradox](https://kristoff.it/blog/static-site-paradox/)
for why.)
It's intentionally barebones, to make things as simple as possible.

This website itself is an example of something you could make following this guide.
In total, [the HTML templates and CSS are under 250 lines of code][repo].

[ssg]: https://en.wikipedia.org/wiki/Static_site_generator

## Getting started

The numbered sections should be read in order.
So, start at [§1. Overview](/overview) for your intro briefing,
then start getting your hands dirty from [§2. Home](/home).

You can also watch a partial speedrun at
<https://youtu.be/SiXSYY4lBNk>.
